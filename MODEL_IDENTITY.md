# KineOne-WM model identity

- Company brand: 勘境 / Kineworld
- Product family: KineOne
- Official model name: KineOne-WM
- Current checkpoint line: KineOne-WM-Latent 0.1
- Historical experiment ID: KINE-EXP-001
- Historical repository: `zoahdev/kine-jepa`

`KINE-JEPA` is retained only as the historical architecture codename used by
KINE-EXP-001. It is not the public model name going forward.

KineOne-WM is unrelated to the pre-existing `KineWorld` entry on third-party
leaderboards. No score, video, checkpoint, or submission associated with that
entry may be attributed to KineOne-WM without an explicit provenance chain.

Any official submission must include the exact model name, organization,
responsible person, contact email, checkpoint hash, code revision, input
manifest, per-output hashes, and official receipt.
